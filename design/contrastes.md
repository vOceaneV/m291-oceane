# Contrastes (WebAIM)
## Éléments conformes 

Titres et textes principaux (Ex: "Bibliothèque", "Mes étagères") :
- Couleurs : Marron foncé sur fond beige crème.
- Ratio estimé : ~9.5:1 
- Statut : Parfait. Le seuil minimal requis est de 4.5:1.

Bouton principal ("+ Nouvelle fiche") :
- Couleurs : Texte blanc sur fond vert sapin.
- Ratio estimé : ~5.8:1 
- Statut : Conforme pour toutes les tailles de texte.

Badges chiffrés ("128", "34", "17") :
- Couleurs : Chiffres blancs sur fond marron terre.
- Ratio estimé : ~7.2:1 
- Statut : Très lisible, excellente accessibilité pour les données chiffrées.

## Éléments non conformes ou limites

Sous-titre et menus secondaires ("Ma bibliothèque virtuelle...", "Recherche avancée") :
- Couleurs : Texte gris-vert olive clair sur fond beige crème.
- Ratio estimé : ~2.8:1 
- Statut : Non conforme. Pour du texte de cette taille (inférieur à 24px), le ratio minimal absolu doit être de 4.5:1.

Texte de saisie indicatif ("Titre, auteur...") :
- Couleurs : Texte gris-brun très clair sur fond blanc (intérieur de la barre de recherche).
- Ratio estimé : ~2.3:1
- Statut : Non conforme. Les textes d'aide dans les formulaires doivent également respecter le seuil de 4.5:1 pour être considérés comme accessibles.
